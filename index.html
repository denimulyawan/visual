Visual

Masukkan data angka → langsung jadi diagram

1 Data

Tempel data dari Excel / Google Sheets, atau ketik manual. Pemisah: Tab, koma, titik koma, atau |. Baris pertama jadi nama kolom.

Klik sel untuk mengedit. Tekan Tab untuk pindah sel. Anda juga bisa menempel blok data dari Excel langsung ke sebuah sel. Baris pertama = nama kolom.

Cara penulisan data
  • 1 kolom angka → tiap angka jadi satu batang dengan label 1, 2, 3, …
  • 2 kolom: kolom 1 label/kategori, kolom 2 nilai.
  • 3+ kolom: kolom 1 label, kolom sisanya beberapa seri (multi-warna).
  • Semua angka: kolom 1 dianggap sumbu X (untuk scatter/bubble), sisanya seri Y.
  • Nilai boleh: Rp 1.500.000, 12,5%, (250) = negatif, 1,2 jt = 1.200.000.
